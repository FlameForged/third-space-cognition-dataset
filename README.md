# Third-Space Cognition Dataset

This repository contains a small exploratory qualitative dataset related to sustained human-AI interaction, conversational AI behavior, HCI dynamics, personalization safety, and AI evaluation.

The dataset is connected to my independent research paper:

**Third-Space Cognition: Interaction-Level Dynamics in Sustained Human-AI Coupling**  
Zenodo DOI: `10.5281/zenodo.18679265`

## Dataset

The dataset includes coded observations from human-AI interaction sessions, including fields related to model behavior, interaction patterns, safety interventions, evidence strength, and coding confidence.

This is not a statistical benchmark or large-scale dataset. It is an exploratory qualitative research artifact intended to support documentation, transparency, and future analysis.

## Research Areas

- Human-AI interaction
- Conversational AI
- Human-Computer Interaction
- AI evaluation
- Personalization safety
- Trust calibration
- Interaction-level model behavior

## Status

Early exploratory dataset. Future updates may include a codebook, expanded observations, and lightweight analysis scripts.
